# Пульс — сайт фитнес-студии (демо для портфолио)

Групповые тренировки в Минске: недельное расписание с фильтрами, запись на занятие со счётчиком мест и листом ожидания, абонементы со сравнением, личный кабинет-демо. Бизнес вымышленный, данные хранятся только в браузере (localStorage), на сервер ничего не отправляется.

**Демо:** https://nkorshun.dev/puls/

## Возможности

- Расписание на 3 недели, сетка по дням (десктоп) и список с вкладками дней (мобильные). Фильтры по направлению, тренеру, уровню, времени дня, залу и «только со свободными местами» хранятся в URL.
- Карточка занятия: места («осталось 3 из 14»), статусы «вы записаны», «в листе ожидания №2», «мест нет», «запись закрыта». Прошедшие приглушены, отменённые перечёркнуты с причиной.
- Запись, отмена, лист ожидания с номером в очереди и кнопкой-симуляцией «кто-то отменил запись».
- 8 тарифов, таблица сравнения, «Оформить» (демо) активирует абонемент в кабинете.
- Кабинет: абонемент с прогресс-баром и заморозкой, записи, лист ожидания, история, статистика, «Выйти», «Сбросить демо-данные».
- Форма пробного занятия с маской телефона +375, валидацией и имитацией запроса (900 мс).
- Доступность: клавиатура, нативный `<dialog>` с ловушкой фокуса, `aria-live` для уведомлений, доступные имена карточек занятий из видимого текста, `prefers-reduced-motion`.
- SEO: title по страницам, Open Graph, `lang="ru"`, JSON-LD `ExerciseGym` на главной.

## Стек

React 19, Vite, TypeScript (strict), React Router, CSS Modules + CSS-переменные, Vitest, oxlint. Без UI-библиотек.

## Бизнес-правила записи

Все правила — чистые функции в `src/lib/rules.ts`, время передаётся аргументом `now`.

| Правило | Где менять |
| --- | --- |
| Записаться можно не позже чем за 30 минут до начала | `BOOKING_CLOSE_MIN`, `canBook` |
| Отмена без списания — не позже чем за 3 часа | `FREE_CANCEL_HOURS`, `cancelPolicy` |
| Нельзя записаться на два пересекающихся занятия | `overlaps`, `findConflict` |
| Нет мест — лист ожидания с номером в очереди | `decideBooking`, `waitlistPosition` |
| Освободилось место — первый в очереди получает его | `releaseSeat`, `promoteFromWaitlist` |
| Списание занятия с абонемента, возврат при ранней отмене | `chargeVisit`, `refundVisit`, `checkMembership` |

## Архитектура

- **Генерация расписания** (`src/lib/schedule.ts`). Шаблон недели (`src/data/schedule-template.ts`) разворачивается в конкретные занятия на 3 недели. Исключения (замена тренера, отмена) заданы по номеру недели и id шаблона; праздники из таблицы `holidays` отменяют занятия автоматически. Занятость мест считается детерминированно: `seeded(id@дата)` даёт число 0..1, вечерние занятия будней заполняются сильнее. После перезагрузки картина не меняется.
- **Состояние кабинета** (`src/context/`). `AccountContext.tsx` держит `useReducer`; вся логика переходов — в `accountReducer.ts` как чистая функция `transition(state, action) => { state, result }`. Контекст сначала вычисляет результат (для уведомления), затем отправляет действие. Каждые 30 секунд обновляется «текущее время» и прошедшие записи уходят в историю.
- **Хранение** (`src/lib/storage.ts`). Обёртка над localStorage: `try/catch`, ключ с префиксом, версия схемы (`SCHEMA_VERSION`). Битый JSON, другая версия или неверная форма данных дают `null`, и кабинет стартует чистым.
- **Фильтры** (`src/lib/filters.ts`) читаются из `useSearchParams` и пишутся обратно с `replace`.

## Деплой на Netlify

1. Загрузите проект в репозиторий GitHub.
2. Netlify: Add new site, Import an existing project, выберите репозиторий.
3. Настройки подхватятся из `netlify.toml`: команда `npm run build`, папка `dist`, редирект `/* → /index.html` (код 200) для SPA.
4. После деплоя проверьте прямой переход, например `/trainers/anna-k`, и вставьте ссылку на демо в этот файл.

Фото первого экрана хранится локально; остальные фотографии загружаются с Unsplash. Шрифты Inter и Unbounded хранятся локально, без runtime-запросов к Google Fonts.

## Техническая заметка: QA 05.11.2026

Кабинет на десктопе использует две независимые колонки-стека: карточки имеют высоту по содержимому, история занимает всю ширину; на мобильных сохранён последовательный порядок. Reducer, статистика и схема localStorage не менялись.

Inter/Unbounded подключены из `public/fonts/` (WOFF2, кириллица и латиница) с `font-display: swap`, запасными шрифтами с подогнанными метриками и preload основного Inter. Лицензии SIL OFL 1.1: [Inter](public/fonts/inter-OFL.txt), [Unbounded](public/fonts/unbounded-OFL.txt); источник файлов лицензий — `google/fonts`, каталоги `ofl/inter` и `ofl/unbounded`.

Hero использует локальные AVIF/WebP в `public/img/`, responsive srcset 640–2400 px и preload в HTML; пути сборки учитывают `/puls/`. Блок статистики первого экрана резервирует высоту до загрузки шрифтов.
