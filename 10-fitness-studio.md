# Проект 10. Фитнес-студия «Пульс»

**Что показывает:** недельное расписание с фильтрами, запись на занятие со счётчиком мест и листом ожидания, абонементы со сравнением, личный кабинет-демо.
**Кому продаётся:** фитнес и йога-студии, танцевальные школы, детские секции, бассейны, единоборства.
**Стек:** React + Vite + TypeScript, React Router, CSS Modules.
**Деплой:** Netlify (SPA).
**Время:** 3–4 часа.

---

## Промпт

```
Создай полностью готовый к релизу сайт фитнес-студии «Пульс» в Минске с расписанием групповых
занятий, записью на занятие с учётом свободных мест и листом ожидания, абонементами и личным
кабинетом клиента (демо). Сайт должен быть энергичным и современным, как у реально работающей студии.
Это демо-проект для портфолио: бизнес вымышленный, данные хранятся только в браузере.

## Технические требования
- React (последняя стабильная) + Vite + TypeScript strict, React Router. CSS Modules + CSS-переменные.
  Без UI-библиотек.
- Данные в src/data/: directions.ts (направления), trainers.ts, schedule-template.ts (шаблон недели:
  день, время, направление, тренер, зал, длительность, вместимость, уровень), memberships.ts,
  halls.ts, reviews.ts, faq.ts, studio.ts.
- Расписание на 3 недели вперёд генерируется из шаблона (src/lib/schedule.ts), с исключениями
  (замена тренера, отмена занятия в праздник). Занятость мест — детерминированно от seed
  (вечерние занятия в будни заполнены сильнее), стабильна при перезагрузке.
- Записи пользователя, лист ожидания и абонемент — в localStorage через src/lib/storage.ts (try/catch,
  версия схемы). Состояние — Context + useReducer (src/context/AccountContext.tsx).
- Бизнес-правила — чистые функции в src/lib/rules.ts с тестами Vitest:
  записаться можно не позже чем за 30 минут до начала; отменить без списания — не позже чем за 3 часа;
  нельзя записаться на два пересекающихся занятия; при отсутствии мест — лист ожидания с номером в очереди;
  при отмене чужой записи (симуляция) первый из листа ожидания получает место; списание занятия с абонемента.
- Структура:
  - src/pages/ — Home, Schedule, Directions, Direction (/directions/:slug), Trainers, Trainer
    (/trainers/:slug), Prices, Account, NotFound
  - src/components/ — Header, Footer, ScheduleGrid (неделя), ScheduleList (мобильный вид), ClassCard,
    ClassModal, Filters, WeekSwitcher, MembershipCard, CompareTable, TrialForm, Toast, Modal, Badge
  - src/lib/ — schedule.ts, rules.ts, storage.ts, dates.ts, format.ts, validation.ts, phone-mask.ts
  - netlify.toml (build "npm run build", publish "dist", редирект /* → /index.html 200), README.md, .gitignore
- Фильтры расписания синхронизированы с URL.
- ESLint и тесты без ошибок, npm run build без предупреждений.
- Mobile-first (375 → 1440). На десктопе расписание — сетка дней недели, на мобильных — список
  по дням с вкладками дней. Без горизонтального скролла страницы.
- Доступность: клавиатура, aria-label у карточек занятий («Пилатес, 19:00, Анна К., осталось 3 места»),
  фокус в модалках, aria-live для уведомлений, контраст WCAG AA, prefers-reduced-motion.
- SEO-мета, Open Graph, title меняется по странице, lang="ru", JSON-LD (ExerciseGym) на главной.

## Дизайн
- Энергичный, но не кричащий: тёмные секции #111214 чередуются со светлыми #f5f5f2, текст #141414 /
  #f2f2f2, акцент неоново-коралловый #ff5a3c, второй акцент холодный голубой #6ec5ff (для «осталось
  мало мест» — янтарный #ffb020). У каждого направления свой цвет-метка в расписании.
- Шрифты: заголовки — Unbounded или Bebas Neue (крупно, плотно), текст — Inter.
- Динамичные фото тренировок в одной гамме, крупные цифры, смелая типографика.

## Страницы
1. **Главная**: hero с видео-плейсхолдером или фото, h1 «Групповые тренировки в Минске — от 7 утра
   до 22 вечера», кнопки «Пробное занятие за 9 BYN» и «Расписание». Блоки: направления (8 карточек),
   «Ближайшие занятия сегодня» (живой список из расписания с местами), тренеры, абонементы (3 популярных),
   залы и студия (фото, площадь, раздевалки, душ, парковка), отзывы, FAQ, форма пробного занятия, контакты.
2. **Расписание**:
   - Неделя с переключением (текущая и 2 следующие), кнопка «Сегодня».
   - Фильтры: направление, тренер, уровень (новички, все уровни, продвинутые), время дня (утро/день/вечер),
     зал, «только со свободными местами».
   - Карточка занятия: время, направление, тренер, зал, уровень, индикатор мест («осталось 3 из 14»),
     статус («вы записаны», «в листе ожидания №2», «мест нет», «запись закрыта»).
   - Модалка занятия: описание, тренер, что взять, кнопки «Записаться» / «Встать в лист ожидания» /
     «Отменить запись». Если нет абонемента — предложение пробного или покупки разового (демо).
   - Прошедшие занятия приглушены, отменённые — перечёркнуты с причиной.
3. **Направления** и **страница направления**: описание, для кого, нагрузка (шкала), ближайшие занятия,
   тренеры направления.
4. **Тренеры** и **страница тренера**: фото, опыт, сертификаты, направления, ближайшие занятия.
5. **Цены**: абонементы (разовое, 4, 8, 12 занятий, безлимит месяц, утренний безлимит, семейный),
   срок действия, цена за занятие, заморозка; таблица сравнения; акции; «Пробное занятие».
   Кнопка «Оформить» (демо) — активирует абонемент в личном кабинете.
6. **Личный кабинет** (/account, демо-вход по имени и телефону без пароля):
   - активный абонемент: осталось занятий, срок действия, прогресс-бар; заморозка (демо);
   - мои записи (предстоящие) с отменой и предупреждением о списании, если до начала меньше 3 часов;
   - лист ожидания; история посещений; статистика (занятий в этом месяце, любимое направление);
   - кнопка «Выйти» и «Сбросить демо-данные».
   Плашка «Демо-режим: данные хранятся только в вашем браузере».
7. **404**.

## Формы (демо-режим)
- Пробное занятие: имя, телефон с маской +375, направление, удобное время, согласие.
- Валидация с понятными ошибками, имитация запроса ~900 мс, экран успеха с номером заявки.
  Неброско: «Демо-режим: данные никуда не отправляются».

## Реалистичность контента
- Направления: пилатес, функциональный тренинг, йога, стретчинг, TRX, сайкл, зумба, «здоровая спина».
- Тренеры: 7 человек, обычные имена с инициалом фамилии, опыт 2–11 лет, конкретные сертификаты.
- Расписание реалистичное: утро 7:00–9:00, обеденные 12:30–13:30, вечер 18:00–21:30, выходные с 10:00.
  Вместимость по залам разная (8, 14, 20). 2 зала + сайкл-студия.
- Цены не круглые: пробное 9 BYN, разовое 19 BYN, 8 занятий 118 BYN, безлимит 164 BYN, утренний 97 BYN.
- Отзывы: в основном 5, есть 4 («в вечерние часы сложно попасть на пилатес»), упоминают тренеров
  по имени и направления; даты последних месяцев; у одного ответ студии.
- Тексты без штампов («тело мечты», «лучшая версия себя», «профессиональные тренеры» — запрещены).
- Контакты выдуманные, но правдоподобные. В футере: «Демо-проект для портфолио. Бизнес вымышленный».
```
